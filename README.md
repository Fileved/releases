# Файловед — установщики

Файловед (Fileved) ищет по всем файлам на ваших компьютерах: документы, сканы и фото,
запросы обычным языком. Сайт — [fileved.ru](https://fileved.ru).

Здесь лежат только сборки приложения. Последняя версия:

- **macOS:** [Fileved-mac.zip](https://github.com/Fileved/releases/releases/latest/download/Fileved-mac.zip)
- **Windows 10–11:** [Fileved-windows-setup.exe](https://github.com/Fileved/releases/releases/latest/download/Fileved-windows-setup.exe)
  или [без установки (zip)](https://github.com/Fileved/releases/releases/latest/download/Fileved-windows-portable.zip)

Все версии — в разделе [Releases](https://github.com/Fileved/releases/releases).
Дальше приложение обновляется само.

Как подключить компьютер к общему поиску — в [кабинете](https://app.fileved.ru).
